# 🖼️ CSS Flexbox Photo Gallery

A responsive, modern photo gallery built using semantic **HTML5** and **CSS3 Flexbox**. This project demonstrates core layout techniques, alignment properties, and responsive wrapping using flexible boxes to showcase a curated collection of feline photography.

---

## 📌 Overview

The **CSS Flexbox Photo Gallery** presents a clean, visually balanced layout designed to adapt fluidly across devices. It showcases how powerful modern CSS layout systems like Flexbox can be used to construct elegant web galleries without complex frameworks.

---

## ✨ Key Features

- **Flexible Layout Engine**: Built with CSS Flexbox (`display: flex`, `flex-wrap: wrap`) to automatically wrap and center grid items.
- **Responsive Design**: Implements maximum constraints (`max-width`) and percentages to ensure proper scaling.
- **Image Fitting**: Utilizes `object-fit: cover` to prevent image distortion across different aspect ratios.
- **Consistent Spacing**: Leverages modern `gap` properties and automatic margins for balanced alignment.
- **Accessible Attributes**: Includes descriptive `alt` text for all images to support screen readers and web accessibility.

---

## 🛠️ Built With

* **HTML5**: Semantic document structure and image integration.
* **CSS3**: Layout styling, Flexbox alignment, box-sizing models, and custom color accents.
